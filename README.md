### 🌤️ Weather App

A modern, responsive weather application built with React and Material UI.
Search for any city and get live weather information including temperature, humidity, and more.

### 🧱 Features
Search for weather by city name

Live weather data using OpenWeatherMap API

Shows:

Temperature

Feels like

Min/Max temperature

Humidity

Weather description

Dynamic icons and images based on weather

### 🛠️ Built With

React

Material UI

OpenWeatherMap API

Vite (for fast development)

JavaScript & CSS
