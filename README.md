# 🌤️ Weather App

A modern, responsive **weather application** built with **React** and **Material UI**.  
Search for any city worldwide and get **live weather updates**, including temperature, humidity, and more.  

> ⚠️ **Note:** This project was created for **practice and learning purposes**. It is not intended for production use.  



##  Features      

- Search weather by **city name**  
- Get **live weather data** using OpenWeatherMap API  
- Displays:
  - Temperature 🌡️  
  - Feels like temperature 🤗  
  - Minimum & Maximum temperature ⬇️⬆️  
  - Humidity 💧  
  - Weather description 🌥️  
- Dynamic icons and background images based on current weather conditions  
- **Responsive design** for mobile and desktop  



## 🛠️ Built With

- **React** – JavaScript library for building UI  
- **Material UI** – Component library for React  
- **OpenWeatherMap API** – Fetch live weather data  
- **Vite** – Fast development environment  
- **JavaScript & CSS** – Core programming and styling
